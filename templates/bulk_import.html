Import Instructions

  1. Prepare your spreadsheet (CSV or Excel format) with the following columns:
    • gisement_no - Gisement number with collector initials
    • collector - Collector name
    • date - Date in YYYY-MM-DD format
    • locality - Primary location
    • locality_details - Additional location information
    • geological_age - Geological age
    • geological_age_subzone - Age subzone
    • laborde_x - Laborde X coordinate
    • laborde_y - Laborde Y coordinate
    • latitude - Latitude (South)
    • longitude - Longitude (East)
    • species_recorded - Species data
  2. Ensure column names match exactly (case-sensitive)
  3. Upload your file using the form below
