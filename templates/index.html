Welcome to the Madagascar Geological Gisement Database

This platform allows you to manage geological gisement data for Madagascar. You can enter single records, bulk import from spreadsheets, and query existing data.

➕ Single Entry

Add individual gisement records with all required fields including location, collector information, and species data.

Start Entry

📊 Bulk Import

Import multiple records at once from CSV or Excel spreadsheets. Download the template to get started.

Import Data

🔍 Query Data

Search and filter gisement records by location, collector, geological age, species, and more.

Query Records

💾 Export Data

Export all records to CSV format for use in other applications or for backup purposes.

Export CSV

📋 Required Fields

  • Gisement No. - With initials of collector as prefix
  • Collector - First name or initials and surname
  • Date - Collection date
  • Locality - Primary location
  • Locality Details - Additional location info (e.g., distance from village)
  • Geological Age - Age classification
  • Geological Age Subzone - Subzone classification
  • Laborde Coordinates - X and Y coordinates
  • Lat/Long - Latitude (S) and Longitude (E)
  • Species Recorded - Species found at the gisement
